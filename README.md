# E-commerce Inventory Analytics

A portfolio project demonstrating Business Analysis, SQL, Python, inventory analytics,
inventory ageing, sales analysis, and business insights using fictional e-commerce data.

## Dataset
All data in this project is synthetic and created for portfolio/interview purposes.
It does not contain confidential company or customer information.

## Files
- products.csv
- warehouses.csv
- vendors.csv
- inventory.csv
- sales.csv
- purchases.csv
- grn.csv
- orders.csv

## Suggested analysis
1. Inventory value by warehouse
2. Inventory value by category
3. Inventory ageing
4. Slow-moving and non-moving inventory
5. Sales vs inventory
6. Vendor performance
7. Inventory turnover
8. High inventory / low sales risk
